步驟 1：簽約資料準備

📁 代書應準備文件清單與填寫規範

文件名稱 提供單位 份數 填寫注意事項與備註說明
1. 協議價購契約書 (私契) 市府 一式 3 份 ※ 金額規定：
• 瓶頸打通：公告現值 × 1.4 倍
• 市價：依估價師查估報告
2. 土地歸戶清冊 市府 一式 3 份 清冊下方備註欄要注意年度。
3. 實價登錄委託書 地政 1 份 依規定完成相關基本資料填寫。
4. 土地登記申請書 地政 1 份 • 登記原因：買賣
• 申請人欄位：
  - 買受人：桃園市 0006800000
  - 管理機關：桃園市政府工務局 代表人:汪在宙 26645701
• 備註欄必填切結文字：
1. 本案出賣土地確無出租，如有不實，出賣人願負法律責任。
2. 本案免繕發權利書狀。
※ 公司戶及未成年子女有另外備註事項需注意！
5. 土地所有權買賣移轉契約書 (公契) 地政 一式 2 份 • 登記以外的約定事項：
「本契約書由桃園市政府收執並持向地政機關辦理登記，得免貼印花。」
6. 土地增值稅申報書 地政 1筆地號 1份 • 協議價購案件都是按現值申報、契約依實價計算。
• 如果前次移轉現值有多筆，改成在出賣人用「前次兩次以上輸入區」。
• 登記原因：協議價購
• 權利人部分合併為一欄：桃園市 管理機關:桃園市政府工務局 代表人:汪在宙 26645701
7. 土地複丈及標示變更登記申請書 地政 1筆地號 1份 （有分割才需要辦理）

❓ 簽約常見問題與解答 (Q&A)
權狀遺失怎麼辦？
事務所可以特別為您代辦，請您準備印鑑證明、印鑑章，權狀遺失需公告 30 天，會造成過戶、發價流程後延。（事務所配合市府才提供免費代辦）
簽約本人無法到場
請所有權人簽好授權書，由受託人攜帶委託人的授權書、簽約資料、受託人的身分證及便章到場簽約。
請問多久可以領到補償金？
您簽約備件完成後，資料會送市府用印，待用印完成即可報稅、查欠、過戶，所需時間大約 2 週，過戶完成會把資料送回市府，接下來就是看市府的作業時間！
※ 稅單核發：4 ~ 7 個工作天
※ 買賣移轉：3 個工作天
是否要繳土增稅？
依據平均地權條例第 42 條規定，免徵土地增值稅。
是否要負擔移轉相關費用？
代書費、規費都由市府負擔。
若土地有他項權利可以簽約嗎？
民眾須先塗銷他項，才能參與協議價購。
為什麼需要提供 2~3 份印鑑證明？
因為承辦不確定您的權狀是否由遺失，若有遺失需有印鑑證明才能代辦，您才不用多跑一次戶政申請。我們過戶完後，所有資料及未使用的印鑑證明都會交還桃園市政府，事務所這邊不會保留您的任何個資！

步驟 3：用印作業規範

📑 1. 分批做用印清冊

  • 備章與刪增字：要蓋備章，並明確標註刪＿字、增＿字。
  • 清冊格式欄位：清冊請在該文件右側新增欄位，表頭設為「訂正章」，並標註「V」。

📚 2. 用印文件排序規範

  1. 私契
  2. 土地登記申請書：A3 文件可以攤開疊一起再對折。
  3. 土地買賣移轉契約書 (公契)：A3 文件可以攤開疊一起再對折。
  4. 土地增值稅申報書
  5. 實登委託書

⏰ 3. 成果檢送時程管制

用印完成返回後，請預先推算並於 50 個日曆天內 檢送成果！

步驟 4：變更編定與分割作業流程

（視案件需求辦理）

1. 送農審表至農業局

將農審表送交農業局審查，核准後送地政局。

📎 應附文件：雙方用印之私契 ＋ 身分證影本
⬇️

2. 地政局核准變更編定

地政局審查核准後，將收到核准函（正式公文）。

⬇️

3. 送分割案件至土地管轄地政事務所

辦理土地分割複丈作業。

📎 應附文件：核准函之公文影本
⬇️

4. 地政事務所辦理分割程序

標準作業程序：

收件 ➔ 測量 ➔ 登記 ➔ 變更編定登記 ➔ 結案
⚠️ 務必再次確認以下重點：
  • 土地分區是否已正確變成交通用地。
  • 確認沒有原地主造成的註記（例如：農舍套繪等）。

步驟 5：報稅作業重點

🌐 地方稅網路申報入口網 🔗 桃園地方稅務局官網

💻 1. 到顧代書生成土地增值稅檔案

  • 開啟「顧代書」 ➔ 點選「準備列印土地增值稅申報書A3」。
  • 前往分頁標籤最右側「增值稅網路申報」。
  • 發生日期為必填項。
  • 點選「按這裡產生增值稅檔案」（土地印花稅不需申報）。

📤 2. 上傳報稅資料

  • 使用自然人憑證登入「地方稅網路申報系統」（選擇報稅代理人）。
  • 路徑：不動產移轉申報 ➔ 整批案件上傳 ➔ 選擇 `.zip` 檔案。
  • 確認是否有標頭檔與土增稅筆數 ➔ 按下「確認申報」。
  • 申報完成後務必下載報稅明細。

✍️ 3. 填寫案件編號與日期

  • 需蓋發生日/報稅日及填寫土增稅案件編號之文件：
    土增申報書、土地登記申請書、公契、實登委託書、私契。
  • 身分證切結文字：
    「本影本與正本相符，如有不實願負法律責任。」

📎 4. 上傳完稅附件

掃描順序（請嚴格遵守）：

  1. 土增申報書
  2. 公契
  3. 私契（正面 + 反面）
  4. 身分證影本
  5. 派工公文
  6. 使用分區證明（都市計畫內土地才有）

系統上傳：憑證登錄稅務局網站 ➔ 不動產移轉申報 ➔ 申報與查詢 ➔ 選桃園市查詢 ➔ 進入案件點選「完稅附件上傳」（選不分檔一次上傳）。

📌 5. 稅單下來後釘法

  • 土地增值稅稅單釘在公契上。
  • 靠右邊留一點空隙、露出總金額；有多張時往左或往下排列，同一批釘法必須保持一致。
  • 裁切時請注意條碼一定要完整保留。

步驟 6：送件作業重點

🧮 連前持分計算 💰 土地登記規費試算 🏠 內政部實價登錄 🆔 身分證核對工具 🔗 桃園地政局轄區地所

📝 1. 申報實價登錄

  • 特殊交易標的：若包含「公共設施保留地（用地）」，當都市計畫內有載明時，一定要勾選。
  • 地號輸入：協議價購已有價購清冊，不須分別打地號。

🔍 2. 送件前檢查

  • 身分證核對：務必再次確認身分證是否為最新資料。
  • 地址不符處理：地址跟身分證不一樣時，在原地址下方寫新址（原本地址不用槓掉）。

步驟 7：領件與進度查詢

🔎 桃園地政案件辦理查詢 🌐 跨域代收案件查詢

🔍 線上案件查詢

  • 桃園市地政事務所案件：可點選右上角「桃園地政案件辦理查詢」按鈕輸入收件字號追蹤審查進度。
  • 跨縣市代收案件：可使用「跨域代收案件查詢」系統即時掌握跨區案件辦理狀態。

📦 領件注意事項

  1. 確認登記完成後，攜帶領件收據及代書印章至地政事務所領取新發權利書狀及公契。
  2. 核對公契收件編號與所有權人資訊。
  3. 核對權利書狀內容（地號、面積、所有權人姓名、身分證字號等）是否完全無誤。
  4. 大溪地政會主動換狀，其他地所若有逕割的，通常只有母地號會幫忙換狀。
